## Local dev
1. Install uv (macOS and Linux)
```
curl -LsSf https://astral.sh/uv/install.sh | sh
```
2. install and use jupyter lab
```bash
uvx jupyter lab
# logout from the menu
# ctrl-c to exit
# kill them
# pkill -f -1 jupyter*
```

## Clone repo
```bash
git clone https://github.com/mxochicale/intro-to-deep-learning-carpentries-lab.git
```
